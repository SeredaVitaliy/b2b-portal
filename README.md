# SV маркет

[Открыть демо](https://sv-market-horeca.netlify.app)

Портал оптовых закупок для кафе и ресторанов Калининграда. В ветке `mvp` закупщик сравнивает предложения нескольких поставщиков по общей карточке продукта и собирает одну корзину. При оформлении каждый поставщик получает свой заказ. Предыдущая версия приложения доступна в ветке `main`.

## Как пройти демо

Откройте каталог и найдите товар через поиск. В гостевом режиме видны фасовка, поставщики и остатки. Выберите «Демо-вход» и войдите как закупщик. На карточке продукта появятся цены. Добавьте упаковки у двух поставщиков, наберите минимальную сумму для каждого и выберите даты доставки. После оформления откройте «Заказы».

Для проверки поставщика выберите предложение «Балтийский урожай». Переключитесь в роль поставщика, откройте полученный заказ и подтвердите его. В кабинете можно поменять несколько цен и остатков за раз, выгрузить и загрузить CSV или отправить новую карточку на модерацию. Закупщик может сохранить содержимое заказа или корзины как шаблон. Менеджер портала видит очередь карточек, участников и споры.

Демо использует общие учебные компании. Достаточно выбрать роль в интерфейсе. Используйте вымышленные адреса и комментарии.

## Технологии

Клиент использует React, TypeScript, Vite, TanStack Query и Ant Design. API работает в Netlify Functions, данные хранятся в PostgreSQL. Начальная миграция создаёт восемь поставщиков, пять заведений, 320 карточек и 960 предложений.

## Сборка и запуск

Для сборки клиента выполните из корня `npm ci --legacy-peer-deps`, затем `npm run build -w client`. Готовые файлы появятся в `client/dist`. Для полного приложения нужны API и PostgreSQL. При импорте репозитория в Netlify выберите ветку `mvp`, корень репозитория и настройки из `netlify.toml`. Миграция находится в `market/migrations`.

Подробности контрактов, модели данных и проверки оформления заказа приведены в [документации](docs/market.md).
